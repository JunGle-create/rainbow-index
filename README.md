# 彩虹指数 Rainbow Index

一个适合 Gay 与拉拉的名字指数计算器，纯属娱乐。

**在线体验：** <https://jungle-create.github.io/rainbow-index/>

## 特点

- Gay / 拉拉 双模式，称号、场景、文案各自独立
- 同一名字，结果恒定
- 六维指数：心动频率、审美雷达、社交电量、情感表达、生活仪式感、缘分磁场
- 彩虹人格、今日幸运色、命定场景、被搭讪概率
- 纯前端单文件，不保存历史、不上传任何数据

## 说明

结果仅为娱乐，不构成任何关于性取向的判断。你是谁，由你定义。

灵感来自 [Gaynum](https://akanyi.github.io/Gaynum/)。
